# 数据源与字段规范

## 一、权威源清单（按优先级）
1. 证券时报、中国证券网
2. 澎湃新闻、每日经济新闻
3. 中新经纬、中国基金报、财联社
4. 新浪财经、东方财富、腾讯新闻（转载稿，用于交叉验证数值）
5. 行情接口：新浪 `hq.sinajs.cn`（`gb_dji` / `gb_inx` / `gb_ixic`、`r_jp225` / `r_ks11`，注意**不要加 `$` 前缀**）

## 二、必备字段
| 字段 | 说明 | 口径 |
|---|---|---|
| 美股三大指数 | 道指 / 标普500 / 纳指 点位 + 涨跌幅 | 美东**前一交易日**收盘（北京时间当日 8:05 时已收盘） |
| 费城半导体指数 | 涨跌幅 | 同上，主题强弱核心指标 |
| 存储/芯片个股 | 西部数据、美光、闪迪、希捷、SK海力士、英伟达等 | 驱动「隔夜美股」段落 |
| 七巨头 | 涨跌分化 | 可选 |
| 日经225 | 开盘点位 + 开盘涨跌幅 | 当日 **08:00 开盘** |
| 韩国KOSPI | 开盘点位 + 开盘涨跌幅 | 当日 **08:00 开盘** |
| 盘中变化 | 「一度涨超 x%」 | 须标注"一度/截至发稿" |
| 驱动事件 | 财报/宏观/政策 | 决定「引爆点」段落 |

## 三、口径铁律
- **开盘 ≠ 盘中 ≠ 收盘**：要点写"开盘涨幅"，盘中数据必须带"一度/截至发稿"字样。
- 早报时点为北京时间 08:05，日韩已开盘 5 分钟，**开盘价即开盘涨幅**为最稳口径。
- 隔夜美股统一写"美东前一交易日收盘"，并给出具体日期（如"美东 10.27 收盘"）。
- 涨跌幅正负必须与原文一致，**不得把"涨"写成"跌"**。

## 四、交叉核对规则
1. 关键数值（三大指数点位与涨跌幅、日韩开盘点位与涨幅）**至少两源一致**方可采用。
2. 来源冲突时优先级：明确标注交易时段 > 数值精度高 > 出现次数多 > 转载层级高。
3. 某源数据与其余全部矛盾时（历史案例：标注为当天却显示低开 -0.31%/-0.83%，而其余 5 源均为高开 +0.74%/+2.23%）**弃用该源**，正文只保留可确认数值。
4. "预期/一致预期"（如 SK海力士营收预期 98.96 万亿）必须写成"预期"，不可与实际值混同。
5. 抓不到可信数据时写"数据待确认"，禁止用推算或记忆填充。

## 五、驱动事件写法
- 由个股/行业财报驱动时，单独设「引爆点」小节：营收/利润（实际 vs 预期）、同比、股东回报、产能或指引。
- 必须写出传导逻辑（美股同板块 → 亚太跟涨），这比罗列数字更有早报价值。
- 若触发 sidecar / 熔断 / 临时停牌，在「重点解读」提示"开盘强势≠收盘无忧"。

## 六、格式约定
- 涨 `#e60000`，跌 `#009944`（0 用中性色），重点数字加 `font-weight:700` + `border-bottom:1px dashed <同色>`。
- 公众号会剥离 `<style>` 块与 class，**所有样式必须写在元素 style 属性里**。
- 五节结构固定：① 一句话定调 ② 隔夜美股 ③ 日韩开盘 ④ 重点解读 ⑤ 今日观察位；末尾附数据来源与免责声明。
- 微信纯文本通道用【红+X%】/【绿-X%】标注涨跌。
